Pilot Pack 01 — Fundamental experiments

Can your agent run a basic lab experiment and correctly read noisy evidence from it? Three fundamental experiments, each tested two ways: control (reach a target within a budget) and interpretation (read recorded evidence and answer).

  • Colour mixing · acid–base titration and pH · concentration by absorbance
  • About 150 double-reviewed interpretation items with raw evidence
  • Control environments at Echo and Pulse, plus a Live episode sample
  • Variants for noise, drift, missing data, new instruments and failure diagnosis
  • An independent holdout we keep for evaluation
  • Acceptance criteria agreed with you before delivery

Environments — Recursive Self-Improvement (RSI)

The agent starts with a working baseline and iterates to improve it. Each task includes a runnable environment and a verifier.

ENV-RSI1
Code and algorithm improvement
Improve a baseline such as a query optimiser or a model training loop. The verifier reruns submitted code from scratch on unseen data.

Environment and data pack deliverables

We agree the deliverables for your selected environment or data pack when scoping the order.

Documentation

  • Environment Card for each environment: goal, interface, scoring, valid range, robustness report
  • Data Sheet for each data pack: contents, schema, provenance, validation
  • Reference results for at least three models where included in the evaluation scope
  • Rights and licence documentation

Delivery

  • OpenEnv-compatible Docker images for packaged environments; run on your own cluster, no outbound network required
  • Live tier as hosted sessions
  • Operational figures: latency, concurrency, complete-run cost
  • Acceptance criteria agreed in writing before delivery

How to order

  1. Choose a catalogue code or start with Pilot Pack 01.
  2. Scope call to agree tasks, volume, tier, exclusivity and acceptance criteria.
  3. Sample of one environment or data pack for your evaluation.
  4. Delivery against the agreed acceptance criteria.
