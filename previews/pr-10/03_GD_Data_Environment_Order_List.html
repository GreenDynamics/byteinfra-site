  1. E1 + T1 as one deal — "we evaluate your model on AISLE, you keep the trajectories"Highest scarcity, producible today, matches the ~10k/trajectory reference; the eval report is the door-opener for researcher relationships.
  2. E2 / V1 task packs (Docker buy-out)Market and pricing already exist (1–3k/task, exclusivity ladder); fastest cash; fits the "show a list, wait for orders" motion.
  3. E3 safety & drift add-onNo competitor offers it; converts the AISLE differentiator into revenue; cheap to attach to any E1/E2 deal.
  4. T3 chemistry RL dataPost-training CoT is the moat; needs the 10-26 verifier framework (mathematical coverage criteria) finished first.
  5. V2 hosted physical verifierNeeds the serverless layer + lab scheduling; sell to 1–2 design partners first.
  6. P1 / P2 / P4Low margin and distillable; use as bundle sweeteners and for 科委 tool contracts, not as standalone revenue.
  7. V3 hosted post-training windowStage-2 product (12–36 mo). Do not quote until the L3 engine exists.

3 · Commercial terms (every SKU)

Exclusivity ladder

Non-exclusive = 1× · 2-month exclusive = 2.5–3× · perpetual exclusive = 5×. Default non-exclusive; the same asset is resold to multiple labs.

Acceptance criteria in every pack

(a) documented performance gap frontier vs target model · (b) anti-hacking checks passed · (c) 8-run variance within stated band · (d) reward-signal usefulness: scores mid-range and stable, not saturated.

Transparency bundle with every run

Token usage, tool-call log, per-box trace, physical test conditions, verifier version.

Task-space statement

Every task declares its explored range and sampling coverage; no capability claims beyond the audited interval; regression vs generation tasks declared separately.

Data handling

NDA + destruction clause for any buyer API access; staged delivery; GD retains verifiers and pipelines. Mainland-generated data stays in mainland; overseas buyers served from the Australian / SEA entity with physically separated data.

Access & customers

White-box access required for E1; black-box only for self-service E2/V1. Frontier and large-model companies and sovereign-AI programs only — no small labs.
