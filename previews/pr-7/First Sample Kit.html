Everything in the grey "later" rows, against acceptance criteria agreed in writing.

Four things that end the deal if missing

  1. It runs on their cluster with one command. A broken sample ends the conversation.
  2. Baselines show headroom. Frontier models at 0% or 95% means nothing to learn.
  3. The reward cannot be trivially gamed. Their RL team tries this first.
  4. Rights are clean. Legal stops the deal even if the tech passes.

1. Data sample

Target: PP-01 interpretation set, about 100 double-reviewed items across colour mixing, titration and absorbance.

2. Environment sample

Target: Echo-S1 colour mixing. Each task gives a target RGB; the agent proposes volumes of dyed stock solutions and gets back the RGB predicted by a model fitted to our real camera and spectrometer runs. 20–50 target colours. Every competent agent can reach the colour, so the score comes from the path: the final ΔE is a gate, then safety and efficiency decide the score. Many different paths score full marks.

ItemDone whenOwner
Task folders20–50 folders, each with instruction.md, task.json, environment/, verifier/, witnesses/—
task.jsonone template shared by all tasks: id, family, tier, version, difficulty, agent and verifier timeouts, CPU and memory, allow_internet false—
Shared base imageone image holds the colour model, propose_recipe and query_history; each task Dockerfile is a one-line FROM—
Rubricone rubric.json: ΔE ≤ 3 as the gate, then weighted safety, attempts and material use; scorer reads every step, never compares recipes to a witness—
Witness check2–3 witnesses per task taking clearly different paths all score full under the current rubric; check.json regenerates on every rubric change—
Baselines + headroom3 models, several runs each; pass@k within the attempt budget and ΔE distribution; share of runs reaching full score roughly 10–60% (tighten the rubric if higher), and compared with random search and Bayesian optimisation at the same budget—
Anti-hacking notetried: probing the twin, interpolating from query history, out-of-range or negative volumes, blind guessing on the first attempt, doing nothing to avoid violations, format tricks; each scored low—
One-command runa colleague outside the team runs it on a clean machine with network off; run.sh also exports the Harbor layout; rough GPU-hours recorded—
Environment Cardone page: goal, tools (propose_recipe, query_history), ΔE scoring, colour range the twin covers, held-out error against real runs—
Rights statementconfirms the S1 runs behind the twin are ours to license—
