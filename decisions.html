团队架构与 Git 协作方式

状态：协作方式已确认；具体业务技术方案仍按各自讨论确认。日期：2026-11-04。

ByteInfra 面向所有协作成员及其 Codex 会话，集中维护整体架构、项目关系、设计决定和重要变化。执行代码与详细开发任务在实施仓库。

  • 文字说明与图共同表达架构，仓库可独立理解，不依赖个人聊天记录。
  • 可视化站点从显式公开清单生成；私有来源证据默认留在内部文件。
  • 设计修改通过 PR 审阅，提供预览和视觉对比，再更新正式站。
  • AI 根据 Git 增量提出整合 PR，每项新增结论附依据。AI 推断不得自动成为团队共识。
  • 任务必须有明确负责人；不能从创建者身份推断执行负责人。

本文件确定协作方式，不预设 runtime、verifier-core 等实现模块已成立。
